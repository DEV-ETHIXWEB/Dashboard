How it is built

The E is three positioned bars rather than an image — x 0–38, rows 3–11 / 28–36 / 52–60, measured straight off public/ethixweb.png — so the animated bars land on the same pixels the artwork does and the finished frame is the real logo, not a lookalike.

THIXWEB is that same PNG used as a CSS mask over a solid fill, which is what lets it turn white, black and white again without a second asset. Nothing here is driven by JavaScript except the Replay button, so the sequence drops into a login splash as-is.

Red comes from the app’s own --primary, oklch(0.50 0.22 29). Reduced-motion viewers get the finished logo on black with no movement.
